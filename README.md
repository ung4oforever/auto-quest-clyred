## 📥 Installation

1. **Download** the latest `AutoQuestClyred.exe` from [**Releases**](https://github.com/ung4oforever/auto-quest-clyred/releases/latest)
2. **Place** it in a folder of your choice
3. **Double-click** to run the app
4. **Paste** your Discord token
5. **Select** the quests you want to complete
6. **Click** `Start`

## ⚠️ Notes

> ⚠️ **Windows SmartScreen** may show a warning the first time you open the app.  
> Click **"More info"** → **"Run anyway"** to proceed.

> 🛡️ **Antivirus false positives** can happen with PyInstaller executables.  
> Add the app to your antivirus exclusions if needed.
