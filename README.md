## <img src="https://raw.githubusercontent.com/feathericons/feather/master/icons/download.svg" width="20" /> Installation

1. **Download** the latest `AutoQuestClyred.exe` from [**Releases**](https://github.com/TU-USUARIO/clyred-downloads/releases/latest)
2. **Place** it in a folder of your choice
3. **Double-click** to run the app
4. **Paste** your Discord token
5. **Select** the quests you want to complete
6. **Click** `Start`
